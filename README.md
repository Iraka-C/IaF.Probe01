## 特性简介

* 1GHz带宽
* 约500kΩ输入，可用转接线支持50Ω输入
* 1:1探头倍率<sup>※输入输出均端接50Ω</sup>
* 最大±2V输入，最大输出不低于±2V<sup>※至50Ω</sup>、±4V<sup>※至1MΩ</sup>
* 可自行更改衰减倍率支持更高电压测量
* 低于5mVrms本底噪声<sup>※1GHz带宽内</sup>
* 低于-60dB谐波失真<sup>※1Vpp正弦</sup>
* 经测试保证2.5kV共模隔离电压
* 仅需一个Type-C供电

更多特性及图表见【性能指标】章节。

> 关于激光管款式
>
> 激光管有各式波长和速率。2.5Gbps激光管我尝试过1310nm和1550nm款。1550nm激光管斜率效率略高，约高出10%，但阈值电流大得多。综合来看1310nm在不严重损失效率的情况下对功耗管理和摆幅设计更友好。
>
> 10Gbps激光管我尝试过1310nm款，和2.5Gbps款相比其效率只有约一半。2.5Gbps已完全能满足1GHz带宽需求。
>
> TOSA用激光管通常封装为TO-56-4，有四个脚。其中两脚为激光二极管，另外的脚可能包含一个监测发光强度用的光电管。一般情况不必使用此光电管，但它可以用作输入级静态电流共模反馈。激光管和光电管pinout各式各样，请在制作前先确认自己使用的型号。详见【调试-一些可以改进方法】。

如果要自己制作光耦则还需要制作一块光耦测试板。因为我是手头有什么用什么，所以没有制作PCB，直接用普通零件在洞洞板上制作了。可根据电路图和自己的元件库存自行设计制作光耦测试板。测试板制作方法请见【光耦制作-测试板】。

* 示波器（任意带宽均可，但如有1GHz及以上带宽的更好）

* 低频信号源（没有专门的信号源可用音频设备输出代替）

* 电源（实验室稳压电源、充电宝等均可）
* 如需制作高阻输入的探头，准备一支φ=2mm陶瓷一字螺丝刀（用于调整可调电容）

## 光耦制作

探头采用自制光耦的路线，但整个电路结构也适用于使用TOSA-ROSA的情况。本节介绍自制光耦的方法。

### 测试板

需要一块测试板来观察激光管和光电管的耦合以及测量光耦成品的参数以决定后期电路调试的方向。测试板电路如下：

<img src=".\images\OPT-Test-Schematic.png" width="50%">

其中1k电位器用于调整激光管静态电流，CH1和CH2可以连接到示波器两个1MΩ输入的通道或两个电压表用于观测激光管LD和光电管PD的电流。激光管每通过1mA电流CH1输出0.1V，光电管每通过1mA电流CH2输出1V。1k电位器建议使用多圈电位器，可更精确调整激光管电流。

BJT可选用任意β>100的小信号三极管，我用的是2N3904/2N3906。

220Ω电阻和电源退耦用的0.1uF电容必须靠近NPN放置，否则NPN可能产生高频振荡。测试时可以将LD-A和LD-K短路并从CH1观察是否稳定。

Vin平时保持开路不接任何输入。如接入信号可在评价光耦特性时用于扫描传递特性曲线（后述）。

使用方法：

1. 将1k电位器调整至下端
2. 将CH1和CH2接入示波器或两个电压表，Vin不连接
3. 在LD座接上光发射器（光耦输入端、激光管、TOSA），PD座接上光接收器（光耦输出端、光电管、ROSA）
4. 为测试板通电5V
5. 调整1k电位器直到CH1的输出表明光发射器达到预期电流
6. 从CH2读到光接收器电流

注意！激光管和光电管均为静电敏感器件。

此外，为方便LD连接可以准备一对测试钩子连线连接LD座和光发射器。

### 材料准备

1. 将三菱UMR-05S笔芯的笔头取下，清理残余的墨水和油，切成9mm长小段（根据激光管焦距确定）
2. 用溶剂洗净残余的墨水和油，晾干
3. 在AD钙奶吸管外缠一层耐高温胶带，切成7mm长小段
4. 将激光管塞入一段吸管
5. 将光电管塞入一段笔芯

### 激光管-光电管耦合

以下步骤基于我买到的LD和PD，如果使用其他光发射/接收器则需要根据数据手册决定具体调整量。
1. 将光电管连笔芯插入测试板PD座
2. 用测试钩子线连接LD座和激光管
3. 将激光管吸管塞入光电管笔芯，注意激光管和光电管引脚方向以方便后续焊接
   <img src=".\images\LD-PD-Orientation.jpg" width="30%" />
4. 通电，调整1k电位器使CH1输出1.50V（LD电流15mA）
5. 上下调整激光管的距离并左右摇晃以使CH2输出电压（光电管上的电流）最大
  
   > 我能调出来的最大电压可以达到1.7V左右，即光电管1.7mA
6. 保持LD位置不动，小心地用牙签蘸取UV胶涂在LD和吸管以及PD和笔芯之间
7. 用紫外线灯固化UV胶。固化过程中会有发热导致CH2输出电压降低，是很正常的事

### 封装

1. 按照胶水的说明配置环氧树脂胶水
  
   > 用于灌封的胶水刚配好会冒气泡以及不太粘稠，可等待三四小时左右稍微粘稠一些了再使用，防止胶水掉落
2. 在耦合好的光耦表面涂抹环氧胶，注意不要涂到管脚和金封底面上
3. 室温下静候24小时固化
  
   > 最好有一个干燥的环境，如加了干燥剂的盒子里。可以尽量避免胶水吸收水气
4. 丰收

### 测试

1. 将光耦用制作时同样的接法接在测试板上
2. CH1和CH2分别接示波器两个通道。示波器调至XY模式，水平CH1垂直CH2
3. 调整测试板1k电位器直到CH1约为1.5V
4. 将低频信号源输出连接至测试板Vin，设置信号源输出为1kHz正弦波
5. 逐渐增大信号幅度直到CH1电压在0.6~2.2V范围变化，记录此时XY曲线形状（截个图！）
6. 根据截图计算制成光耦的阈值电流和斜率效率

## 安装与调试

安装过程不必多说，照着焊就行。遵循以下焊接顺序可以让安装顺利进行：

【电源部分】

1. 首先焊接所有背面SMD元件，除变压器T2和C29之外。
2. 焊接正面SMD元件，除变压器T1, RV1, R43, R44, R45, R46, R19和发射器虚线框内不安装的元件以外
3. 焊接Type-C插座
4. 焊接正反面变压器T1, T2
5. 测量Type-C插座正负有无短路，隔离侧电源输出有无短路。有则排查
6. 焊接所有插件电解电容
7. （可选）在U3的1和2脚以及15和16脚之间各直接焊一100nF 0603或0402电容，与封装越近越好：
   <img src=".\images\PCB-Assembly05.jpg" width="30%">
8. Type-C插座通电，观察测量±6V、±2.5V、隔离测5V电压是否正常，D7是否正常发光。

【信号部分】

1. 焊接输入MMCX座和输出SMA座，焊锡要饱满可以多堆一堆以增强机械强度
   * 输入的MMCX座焊盘亦可兼容SMA座，但SMA座在高阻输入下表现不如MMCX，根据需求自选
   * 焊盘上有两面打通的过孔，因此焊一面时焊锡会漏到另一面。这是正常现象，多漏一点也无所谓
   * MMCX座可以先焊正面再焊背面，这样锡往正面漏得更多
   * MMCX背面的焊盘边缘也可以和座子本身用锡连在一起增加强度
     <img src=".\images\PCB-Assembly03.jpg" width="30%">
   
2. 焊接光耦D2-PD1和D5-PD2
   * 激光管LD+/LD-以外的引脚**全部剪掉**！其它引脚剪至合适长度。
   * 剪线时注意尽量减少PD处引脚长度。焊接顺序为：PD-和GND → LD+和LD- → PD+
     
     > 如果想实现更好的CMRR和THD表现，可以在焊接PD+之前先进行接收端电阻匹配。详见【调试-接收端电阻匹配】
   * 焊接光耦时动作迅速，每个焊点不要加热超过3秒钟，以免损伤光电器件或导致光耦形变。
   * PD+引脚自己掰到焊盘上方去：
     <img src=".\images\PCB-Assembly04.jpg" width="30%">



### 调试

> 注意：原理图中以橙色字注明各位置典型的电压大小。如使用不同元件，电压大小可能有差异，仅供参考。

【激光管电流】

上述安装确认无误后首先调整激光管电流。目标是让最终输出达到开路摆幅±5V。

<img src=".\images\PCB-Adjust01.jpg" width="50%">

假设输出5V，光电管所需电流摆幅可按上图计算：

$$I=\frac{5V}{(1+\frac{510\Omega}{180\Omega})(1+\frac{300\Omega}{50\Omega})\times 2 \times 43\Omega}\approx 2.2mA$$

**以之前制作的光耦为例**，观察光耦特性曲线可知输出0.5mA以下非线性较强，故增加一点电流到2.2+0.5=2.7mA作为光电管静态工作点：

<img src=".\images\OPT-Test-Example-LPDA004-curve.png">

此时对应的激光管电流为19.3mA，可直接取20mA。两个激光管共需电流40mA。

40mA电流在R5上产生电压40mA×5.1Ω=204mV，以此为目标调整激光管电流。

安装R19=1kΩ，通电并测量R5上端电压是否在204mV。若电压不足则减小R19，电压过高则增加R19。切勿长时间维持电压过高状态以免烧坏激光管。

【调试输入/输出倍率①-50Ω】

接下来以50Ω输入为标准测量输入到输出的倍率用于计算衰减器。（但暂不安装衰减器，之后再说）

安装电阻R7=50Ω, R9=0Ω。在C11焊盘上连接一射频线猪尾巴，或者在R8, R15, R14, R16全部焊上0Ω电阻。

安装0Ω电阻 R43, R44, R45, R46，通电检查有无短路。输出是否稳定。（输出可能不是0V，有噪声，但不应该有很大跳动/振荡）

保持通电10分钟以稳定光耦状态。

用信号源在输入施加1kHz 1Vpp正弦波，输入输出均接到示波器。示波器设置为输入通道为1M（因为探头PCB上已做50Ω端接），输出接到50Ω通道（示波器无50Ω则使用50Ω适配器），最好开启波形平均/高精度测量（增加bit数）。用示波器测量输入和输出的交流有效值。

> 示例：测得输入0.354mVrms，输出1.181Vrms，输出是输入的A=3.34倍

> 注：如果激光管电流都非常大了仍然无法满足光电管静态电流/输出倍率的要求，可以考虑牺牲一些带宽和底噪，增大OPA855/OPA695放大倍数

【调试频响①】

使用 带跟踪源的频谱仪/网络分析仪/射频信号源+示波器FFT 测量此时的S21曲线。设定输入信号强度-20dBm左右为宜。

> 注意：如果使用示波器FFT，窗函数要选择平顶(flattop)窗

多半不好看，会呈现如下形态：

![PCB-Test-S21-01.png](.\images\PCB-Test-S21-01.png)

S21曲线一开始会有上升/下降（初始斜率），这是输入MOS管电容导致的一阶衰减。然后会有两个峰。峰A位于500-600MHz，是由OPA695反馈回路控制的，峰B位于900MHz，是由OPA855反馈回路控制的。

我们的目标是将S21曲线在100-900MHz范围调平至±1dB，按如下顺序调整（越靠前的应越优先调整，只有当前一项调整效果不好了再考虑下一项）：

| 步骤         | 调整的元件 | 备注                                                         |
| ------------ | ---------- | ------------------------------------------------------------ |
| 调平初始斜率 | R35, R11   | 和MOS输入电容一起直接控制一阶极点位置<br>初始斜率为负（下降趋势）则减小电阻，为正（上升趋势）则加大电阻 |
|              | C10, C22   | 提供高频boost，电容量越大则初始斜率越正。注意过大的电容可能会影响峰B的调试<br>两个电容串联可以微调其中一个让调节更精确，不一定要两个一样大 |
| 调整峰A      | R12, R18   | R12越小峰A越隆起，越大则峰A越平坦<br>峰A可以影响300-1000MHz范围内的整体响应，但以600MHz为中心的影响最大<br>调整R12时要相应改变R18以维持OPA695级的增益为4左右<br>（例如R12改为430Ω，则R18要换成150Ω再测） |
| 调整峰B      | R10        | R10和OPA695的输入电容一起为OPA855的反馈回路添加一些相位滞后产生峰B<br>R10越小，峰B越高 |
|              | R42        | R42改变光电管偏置电压，导致结电容变化进而影响带宽<br>R42越大，光电管偏置电压越低，结电容越大，峰B越高<br>注意过小的R42可能会导致光电管过载而击穿 |
|              | R28        | R28默认为0Ω，但加入一定量的R28可以和OPA855输入电容一起产生相位滞后<br>R28越大，峰B越高。注意R28不得超过20Ω<br>此外如果OPA855产生2-3GHz的寄生振荡，少量R28也可以抑制这些振荡 |

调平频响以后，如果将探头用于固定50Ω输入则不用再进行之后衰减调整。如将探头制作为高阻输入则需要进一步计算衰减器。

【调试输入/输出倍率②-1MΩ】

> 注：在接下来的步骤中你可能会想在单端化的条件下调试。请先参阅见下一节【调试-单端化】再开始制作！

如果调整过R12和R18则需要重新进行【调试输入/输出倍率①-50Ω】步骤计算放大倍率A。下面以A=3.34倍为例。

首先确定目标倍率。探头输出最多为±2V，所以如果想测量更大的电压就需要更高的衰减倍率，例如输入范围为±10V那么衰减倍率应该为5倍。下面以衰减倍率1倍的制作为例。

> 1MΩ衰减器计算：
> 输入衰减倍率=总衰减倍率*A=3.34，半侧总电阻=500kΩ
> 下端电阻(R7, R9)=500kΩ/3.34=149.7kΩ
> 上端电阻(R8, R14)=500kΩ-149.7kΩ=350.3kΩ
> 取近似E24阻值150kΩ和360kΩ，如果有更精密的电阻或者可以并联得到更精密的阻值也可以使用。

拆除R7, R9, R8, R15, R14, R16，换上计算得到的电阻。R15和R16换成22Ω。

在C11焊盘上安装可调电容。

> 电容C8, C30计算：
> 如果C11安装1.5-3pF可调电容，可以将C11及TVS、MOS总输入电容看作约4.5pF，半侧即为9pF
> 则上端电容(C8, C30)=9pF*150kΩ/360kΩ=3.75pF，可选近似的4pF电容。手头没有的话5pF也可以，反正都可以调。

按计算结果安装好C8, C30。

【调试频响②】

安装好衰减器后应重新调整低频/高频频响。将50Ω转接线接上探头并通电预热10分钟，然后执行下列步骤：

1. 倍率检查：用信号发生器输出1Vpp正弦波至50Ω转接线，输出至示波器50Ω，观察输出是否与输入一样大
2. 低频频响：用信号发生器输出1Vpp方波至50Ω转接线，用陶瓷螺丝刀调整C11至方波顶端和底端均水平
3. 高频频响：重新执行一遍【调试频响①】的步骤，输入至50Ω转接线
   * 由于这次多了一个R15和R16，可以通过调整这两个电阻来影响初始斜率。从不影响50Ω输入特性的角度（S11更好）来看，R15和R16越大越好。但R15和R16越大则初始斜率越负，需要调整R35, R11及C10, C22补回来。R15和R16太大就怎么都补不回来了。22Ω应该是一个不错的初始值，但请根据自己板子的情况综合调整。

调试完成后应能达到900MHz内±1dB，1GHz不低于-3dB的目标。调平后频响的实例见【性能指标】章节。

### 一些可以改进方法

#### 接收端电阻匹配（已实现，推荐）

实际制作出的光耦不可能一模一样，阈值电流和斜率效率上多少有些差异。虽然直接用也没有问题（CMRR主要由电气隔离间隙提供，LTP的CMRR不是主要来源），但本着“要做就做到极致”的想法尽量增大CMRR和减小THD，推荐进行接收端电阻匹配。

接收端电阻匹配通过调整两个光路最终的增益来实现对称的信号传输（相同斜率效率）。这个步骤最好和焊接光耦同时完成。如果安装完成后想实现接收端电阻匹配就需要卸下一些电阻再飞线出来做。下面是同时完成的步骤。

在焊接好光耦的发射端LD+/LD-和接收端的PD-/GND引脚（PD+悬空不焊接！）后，先完成发射端所有元件的安装和激光管静态电流调试，然后将两个光电管的PD+和接收侧GND共三根线（可用测试钩子）引出到面包板上，按下图接好。Ra1是一个2~10kΩ的多圈电位器。
<img src=".\images\R-matching.jpg" width="50%">

将示波器CH1和CH2连到Ra1和Ra2上端，使用1MΩ交流耦合。为探头供电并预热10分钟，用信号发生器在在探头输入端加上1Vpp正弦波，此时CH1和CH2将会出现方向相反的波形。打开CH1和CH2交流有效值测量，调整Ra1直到两通道交流有效值相同（或者打开CH1反向并调整Ra1到两通道波形重合）。此时取下Ra1和Ra2并用万用表测量阻值（Ra2也要测！标称1k总还是有误差），然后通过：

$$R4:(R27||R23)=Ra2:Ra1$$

在R27=50Ω, R23=300Ω时即为

$$R4=\frac{Ra2}{Ra1}\times 42.86\Omega$$

得到最理想的R4大小。安装接收端时在R4安装与计算值最接近的电阻。


#### 单端化（已实现，推荐）

单端化是指将LTP用作单端输入的放大器，可以提高共模抑制比(CMRR)

由于Q3不可能两半完全相同，靠LTP和输入衰减网络提供CMRR不如依靠输入和输出之间的隔离来提供CMRR，所以LTP完全可以单端化使用。单端化后LTP能容纳的输入差分电压减半，同时Q1集电极将看到电压摆幅（不过Q1集电极电容量很小所以问题不大）。LTP将不提供共模抑制，只起到稳定DC飘移和抵消光耦谐波失真的功能。单端化后，输入阻抗也会减半（只有500kΩ），所以如果要1MΩ输入需要重新计算衰减器。

最好的单端化方法当然是输入衰减器只保留Q3.2的一半，Q3.1栅极直接接V_ISO。但是由于这个板子从设计开始已经做成这个样子了，这里只提供简单一点的办法：将J4负极直接接到V_ISO。只需在C29位置焊接0Ω电阻即可。如果不需要直流单端化<sup>（例如音频应用……但谁会这么干呢？）</sup>则将C29位置焊接100pF电容。

其实要是能直接修改原理图并重新制作PCB当然是更好的办法，这也是为什么本项目没有提供立创工程内PCB——有兴趣可以自行修改原理图后重新布线。

#### 激光管内置监测PD共模反馈（已实验，未实现）

许多激光管内置一个光电管用于监测光强度，用于在温度变化的时候调整激光管电流防止烧毁或功率不足。典型的激光管出光功率与温度特性如下所示：
![LD-characteristic.png](.\images\LD-characteristic.png)
温度升高后，如果保持静态电流不变，则由于阈值电压升高，可用的电流摆幅会减小。

共模反馈（CMFB）用于控制出光功率稳定来抵消温度造成的阈值电流变化。一个我试验过可用的方案如下：
<img src=".\images\LD-CMFB.png" width="30%">
其中两个光电管均为激光管的内置PD。静态电流由Iset控制。此时Iset应设置为内置PD对应的电流，Iset可简单地用电阻实现。可以用之前制作的光耦测试板测试激光管自身的LD-PD特性曲线来决定Iset大小。

最后没有在开源出来的板子上实现的原因有两个：
1. 不同激光管LD和PD的引脚排列大相径庭，而且有些LD和PD有共用引脚（共用的方式也千差万别），无法保证你买到的激光管适用于我设计的电路或焊盘。最好根据自己买到的LD pinout决定电路结构和焊盘形状。
2. 由于LD和PD之间存在一些耦合而PD接地。这会导致LD与隔离电源地之间的寄生电容增大，影响带宽，对超过500MHz的S21调整不利。（可能会产生一个很大的坑！）

如果想施加CMFB请自行实验。
